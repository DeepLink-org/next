# 社区

DeepLink Next 是围绕国产异构算力、AI4S 和 Agent Runtime 建设的开源生态。社区项目按能力边界分为四个大模块：**训推框架**、**智能体运行时**、**超智融合计算** 和 **下一代算力架构**。

## 四大模块

<div class="grid cards" markdown>

- :material-brain:{ .lg .middle } __训推框架__

    面向模型训练、后训练、推理框架与推理服务化，沉淀从预训练到在线服务的基础软件栈。

    **项目**：AllSpark / NexRL / Energon / Teletraan

- :material-robot-outline:{ .lg .middle } __智能体运行时__

    面向 Agent 的分布式执行、状态持久化、运行时诊断与安全沙箱，让长期任务可以规模化运行。

    **项目**：Pulsing / Persisting / Probing / 分布式沙箱

- :material-atom:{ .lg .middle } __超智融合计算__

    面向科学计算与 AI 融合，建设科学算子、科学数据压缩、混合精度与工作流编排能力。

    **项目**：科学算子 / 数据压缩 / 混合精度 / 工作流

- :material-memory:{ .lg .middle } __下一代算力架构__

    面向跨域互联、超节点和软硬协同设计，沉淀 Across、Fabric、架构规范、白皮书与参考实现。

    **项目**：DeepLink.Across / DeepLink.Fabric / SuperPod 白皮书

</div>

## 如何参与

<div class="grid cards" markdown>

- :material-github:{ .lg .middle } __贡献代码与文档__

    在 GitHub 上提交 Issue、PR、文档修订和示例。适合已有明确问题或实现方案的贡献者。

- :material-plus-circle-outline:{ .lg .middle } __申请项目收录__

    将与 AI4S 基础设施相关的开源项目纳入 DeepLink Next 生态，获得站点展示、技术讨论和社区资源支持。

- :material-file-document-edit-outline:{ .lg .middle } __参与 RFC 与路线图__

    围绕接口规范、系统边界、项目集成和版本路线提交设计提案，推动跨项目协同。

</div>
